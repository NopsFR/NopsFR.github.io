## Overview

**reversed** is a marketplace platform demonstrating full-stack Next.js development with production payment processing, bot automation, and multi-layered authentication.

---

## Key Features

✅ **Marketplace Core**
- Product listing + search
- Checkout flow
- Order management
- User reviews + ratings

✅ **Payment Integration**
- Stripe Checkout
- Subscription management
- Invoice generation
- Payment webhooks

✅ **Discord Integration**
- Bot notifications
- Community features
- Automated fulfillment
- User sync

✅ **Authentication**
- Email/password auth
- Social OAuth
- Discord OAuth
- Two-factor optional

---

## Technical Highlights

**API Routes**: Next.js handlers for payment processing, webhooks, bot commands  
**Database**: MongoDB via Mongoose  
**Real-time**: Discord bot updates, webhook notifications  
**Security**: bcryptjs for passwords, jose for JWT tokens
